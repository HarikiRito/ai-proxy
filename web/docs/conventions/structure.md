# Structure

Folder layout and import conventions. See also [naming.md](naming.md).

- **No `src/lib`** - flat structure directly under `src/`
- **Subpath import** - `package.json` `imports` maps `#src/*` to `./src/*`; every cross-module import uses `#src/...` (with file extension, `.js` for `.ts` files), never `$lib`, `src/...` or `@` aliases
- **Feature-folder pattern** - each feature lives at `src/features/<name>/`:
  - `<name>.svelte.ts` - reactive state factory (only when the feature has state), see [state.md](state.md)
  - `index.svelte` - the feature's full markup, local UI state, and event-handler wiring
- **Routes are pure delegation shells** - `+page.svelte` files contain no markup, no logic, no state; they only import and render a feature's `index.svelte`
- `src/components/ui/` - shadcn-svelte primitives (generated) plus optional `App*` wrappers, see [components.md](components.md)
- **No hand-written barrels** - no `index.ts`/`index.js` files that exist only to re-export; import the concrete module directly. Barrels add indirection, make navigation harder, and invite import cycles and dead re-exports. Two exceptions: `src/components/ui/*/index.ts` (generated by the shadcn-svelte CLI and regenerated on every `add`; components import each other through them) and `src/utils.ts` (a facade, not a convenience barrel - shadcn-generated components hardcode `import ... from '#src/utils.js'`)

## Tree

```
src/
  components/ui/         # shadcn-svelte button, sonner + AppSonner, AppThemeToggle
  features/auth/
    auth.svelte.ts       # createAuthStore(): WorkOS AuthKit session, owner check via GraphQL viewer, authFetch
    auth.svelte.test.ts
    index.svelte         # guard: sign-in / refused / error screens, admin shell (email + sign-out)
    login.svelte         # /auth/login: starts sign-in
    callback.svelte      # /auth/callback: completes the code exchange
  features/home/
    health.svelte.ts     # createHealthStore(): GET /healthz probe
    health.svelte.test.ts
    index.svelte         # app home + health indicator
  features/providers/
    presets.ts           # 8 provider presets (prefill only)
    providers.svelte.ts  # createProvidersStore(authFetch): providers/keys CRUD via GraphQL, draft form state
    providers.svelte.test.ts
    index.svelte         # providers page (list, keys, capacity); provider-form/key-form dialogs
  features/proxykeys/
    proxykeys.svelte.ts  # createProxyKeysStore(authFetch, clipboard): proxy keys via GraphQL, one-time secret reveal, parseModels
    proxykeys.svelte.test.ts
    index.svelte         # proxy keys page (create, table, reveal dialog, allow-list edit, revoke)
  utils.ts               # re-export facade (cn, bits-ui types)
  routes/
    +layout.svelte       # app shell
    +layout.ts           # SPA config (ssr=false, prerender=true)
    (app)/+layout.svelte # wraps pages in the features/auth guard
    (app)/+page.svelte   # delegates to features/home
    (app)/providers/+page.svelte  # delegates to features/providers
    (app)/proxy-keys/+page.svelte # delegates to features/proxykeys
    auth/login, auth/callback  # delegate to features/auth
  app.css                # Tailwind v4 CSS-first config + shadcn tokens
```
